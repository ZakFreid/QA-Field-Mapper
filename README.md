УСТАНОВКА

1) Скачайте и распакуйте все файлы в одну папку на рабочем компьютере
2) Откройте браузер и перейдите на страницу browser://extensions/ (Например: chrome://extensions/)
3) Включите режим разработчика через специальный тоггл для сборки кастомных расширений для браузера
4) Нажмите на кнопку "Загрузить распакованное решение" и укажите путь до распакованной папки
5) Запустите расширение (теперь оно должно отображаться во вкладке расширений, дальнейшее включение и выключение расширения можно указывать в главном popup-окне самого расширения через кнопку "Вкл/Выкл")

ИНСТРУКЦИЯ ПО ПРИМЕНЕНИЮ

Это кастомное расширение для браузера, позволяющее в автоматическом (на основе эвристики) и ручном режиме связывать любой UI эл-т с параметрами из API-запросов, либо кастомных параметров, указанных пользователем

Изначально при загрузке страницы, расширение постарается само определить доступные для ввода поля и компоненты, а также read-only поля, каждый компонент системы на странице попадёт в одну из трёх категорий:
Зелёное - расширению удалось однозначно сопоставить наименование параметра со стороны backend и привязать его к полю
Оранжевое - данный компонент является одним из параметров, передаваемый в GET или POST запросе, но расширению не удалось однозначно связать наименование параметра и UI эл-т в автоматическом режиме
Без подсветки - сторонний UI эл-т, который не хранит и не принимает никакую информацию ни со стороны клиента, ни со стороны пользователя

Для просмотра информации по интересующему полю, достаточно навести курсор мыши возле подсвеченного UI эл-та, и расширение само покажет всю необходимую информацию, а именно:
1) Текстовый лейбл эл-та, которым оно обозначено на стороне клиента
2) Смапленный параметр из API, относящийся к данному эл-ту
3) String-значение выбранного эл-та
4) Абсолютный XPath выбранного эл-та

Если при обнаружении полей, автоматический метод дал сбой и определил часть эл-тов как информационный параметр, или наоборот не определил какое-то поле, то для этого в расширение заложена ручная настройка

Для перехода в ручной режим, необходимо нажать на клавишу "F"(ind), курсор мыши сменится на инспектор, который позволит указывать любой UI эл-т системы
Если в режиме поиска, навестись на связанный UI эл-т и нажать на кнопку "Del", то такой эл-т будет принудительно удалён из карты объектов и НЕ БУДЕТ отображаться на экране, пока пользователь вновь не выберет его
Если в режиме поиска, навестись на несвязанный UI эл-т и кликнуть по нему, то расширение добавит его в карту объектов и будет хранить его, пока пользователь не удалит его через Del метод, или не очистит его из карты объектов страницы
Если в режиме поиска навестись на связанный UI эл-т и кликнуть на него, то появится окно поиска, показывающее все параметры, которые пассивный сниффер перехватил на данной странице, это позволяет вручную найти значение из json запроса/ответа и указать параметр для поля

При нажатии на значок расширения в браузере, пользователь увидит хранимый справочник, сам справочник состоит из следующей структуры:
1) Host - Корневая папка, содержащая в себе подмножество страниц
2) Slug - Имя страницы, содержащая в себе подмножество связанных параметров
3) Список параметров, в котором отображается лейбл | paramName | кнопка "Фокус на эл-те" | кнопка "Копирование XPath | кнопка "Редактирование связи" | кнопка "Удалить"

4) Расширение поддерживает экспорт/импорт параметров для загрузки в txt и json форматах
